## 2. 已确立的事实(有实测支撑,**不要重新验证**)

### 2.1 失败点在"选择",不在检索或配准

| 组件 | 结论 | 证据 |
|---|---|---|
| RHPD 检索 | **没问题** | 真值 20/20 在 rank ≤4;两张不同地图上真值分别 85/85、65/65 帧排第一 |
| ICP 配准 | **没问题** | 种子正确时 0.020–0.187 m、yaw 0.01–0.45° |
| **从 TopK 选真值** | **这是失败点** | 见 2.2 |

**描述子是对的,选择阶段推翻了它。**这条在 2026-07 就已确立;
2026-08 的 review 又独立重推了一遍(85/85),**属于重复劳动**。

### 2.2 五种独立方法全部无法区分真值与感知别名

| 方法 | 结果 |
|---|---|
| ICP fitness / 残差 | 重叠 |
| 可见性一致性 | 重叠(12 案例中 8 对)—— **但它是全集上最优的标量** |
| 累计对数似然 | 重叠(7 对) |
| 稠密内点率 / 内点数 | **饱和在 1.0**(1 m 对应阈值室内处处满足),无信息 |
| TEASER++ 最大团 | **反向**:别名团是真值的 2.3 倍,且精确命中别名位姿 |

> **不是五个算法都不行,是它们在解同一个无解的问题。**

**这条是整个项目最重要的一句话。**任何"再加一条独立证据/再换一个标量"的方案,
**在提出之前必须先说明它为什么不会是第六个重叠的标量**。

### 2.3 自由空间是唯一方向正确的信号,而关键在归一化

真射线投射(118.8 万条射线,46,573 free 格,2.7 s):

```
  4 个错误位姿   occupied% 全部 ≤68.9%
  13 个正确位姿  10 个 ≥79.8%
```

严格判据仍重叠,**重叠来源已查明**:三个掉队的正确案例 unknown 占比
42.6% / 26.5% / 24.4%(query 看向地图未观测区),**不是位姿错误**。

**按有证据格子归一化后**:正确 [75.7–98.4%] vs 错误 [72.8–90.2%]。

这正是 `FreeSpaceGrid::Score` 里 `known_points` 与 `scored_points` 分开的理由,
也是 `VisibilityConsistency` 缺的东西(它的分母是全部观测 bin)。

### 2.4 唯一有效的机制:证据不足时拒绝下结论

`wip/evidence-baseline` = `581398e`:接受前要求支撑观测跨越
`reloc_static_agg_max_translation`(0.25 m)/ `max_rotation`(0.20 rad)。
**不引入新参数** —— 复用代码自己定义的"视角变得独立"的边界。

```
  72fa6f7 基线          12 对   5 错   3 不锁
  + 视角基线闸门         5 对   0 错  15 不锁   ← 唯一零误锁配置
  + 证据持久化           8 对   2 错  10 不锁
  候选(Atlas+唯一性)     1 对   8 错  11 不锁   ← 已证伪
```

**零误锁是可以做到的,代价是正确数掉到 5。**这是当前唯一已知能满足
"零错锁"的配置。

### 2.5 证据寿命只有 5 帧(结构性缺陷)

`relocalize()` 末尾的 `clearRelocHypotheses()` 在 accept/reject 之后,
**每次接受失败销毁全部假设**。实测每 episode 能积累的视角基线峰值仅 **1–3 cm**,
而机器人实际走了 **0.74–12 m** —— **差两个数量级**。
17 次锁定中 7 次发生在 frame 4(窗口刚满的第一时间)。

保留假设的机制存在(`N3MAPPING_RELOC_PERSIST`),默认关闭,实测 8 对 2 错。
代码注释写明它还缺什么:**"a free-space test that accumulates contradiction
across independent viewpoints, rather than comparing argmax identity every frame"**。

### 2.6 地图重力未对齐(独立缺陷)

地图整体倾斜 **4.14°**(平面拟合 z = 0.01375x − 0.07102y − 1.921),
92 m 跨度产生 6.64 m 假 z 漂移。

- 解释了别名与真值的 Δz(3.0 / 2.5 / 1.3 m)—— **它们物理上同高**
- 解释了 gravity-constrained matcher 为何没兑现 —— 一直对着偏 4° 的基准做约束
- **但修好它不会改变那三个错锁**:重力只约束 roll/pitch,歧义在 x/y/yaw

### 2.7 数据集的物理限制

today20 的 20 段 query **全部落在建图那次遍历内部**(395.6 s / 824.9 s,占 48%),
留出性完全依赖 exclusion windows,**窗口内视角基线只有 1–3 cm**。

> **该数据集在物理上无法验证任何依赖运动的方法。**

**任何依赖"机器人走一段路"的方案,在 today20 上测不出来,必须先解决数据。**

## 3. 下一步

### 3.1 零风险、立刻有收益

**把四个环境变量升成 config 字段**:`N3MAPPING_FREESPACE_SELECT` / `_MODE` /
`RELOC_PERSIST` / `_MAP_PCD`。默认值照抄现状,零行为变化。
但 provenance 第一次能记录这些开关,并自动纳入守卫测试。

**现在一次运行的行为取决于没有被记录的东西。**

### 3.2 六个测量,决定后面所有方向

| # | 测什么 | 能否定什么 |
|---|---|---|
| 1 | RHPD 召回按**朝向差**分层(<45° / >135°) | 若前者显著高 → 24% 源于视角反转 |
| 2 | RHPD 召回按 **PCA 置信度**分层 | 若高置信层 Part A 更差 → 置信度门用反了 |
| 3 | RHPD 召回按**场景类型**分层 | 与 2 互为印证 |
| 4 | 跑**不带 atlas** 的路径,量 RSS 与 p95 | 惰性无缓存的上界 |
| 5 | **单个子图** prepare 耗时 | 惰性方案的每次代价 |
| 6 | 候选集**帧间重叠率** | 缓存命中率 = 真实代价 |

### 3.3 架构改动(依赖关系)

```
  验证模块合并(建图侧与重定位侧各有一半独立证据,且不重叠)
     └→ 完成后才能撤 Scan Context

  可见性归一化:分母从"全部观测 bin"改成"有证据的 bin"
     ← 2.3 已经实测过这个归一化能把重叠分开

  退化检测进判据(信息矩阵已经在算,零算力)

  图优化:迭代式重线性化(参考 GLIM,建图离线有余量)
```

细节见 `n3mapping_architecture_review.md`。

### 3.4 必须先想清楚的一件事

**2.2 说五个标量全部重叠。**所以:

- "把可见性归一化修好"是**有实测支撑的**(2.3 给了分开后的区间)
- "再加一条独立证据链"**没有** —— 必须先回答它为什么不是第六个重叠的标量

**当前唯一被证明能做到零错锁的,是 2.4 的"证据不足就拒绝",代价是正确数 5/20。**
把它从 5 提到 15,才是真正的问题。而 2.7 说**这个数据集测不了依赖运动的方法**。

## 4. 已被数据推翻的路线(**不要重做**)

1. 等价性合并只在 region 内 —— 本就是跨 region complete-link
2. 同地点多 anchor 误算为多 mode —— 实为多 yaw 假设,物理分离 175–193°
3. 要求窗口内有运动 —— 唯一正确锁定的窗口位移最小(0.068 m)
4. `T_map_odom` 倾斜可判别 —— 被各 query 自身 LIO 世界系朝向主导
5. 重力对齐误差可判别(逐帧均值)—— 地图重力自身漂 9.73°
6. 可见性系统性反相关 —— **挑样本的错误结论,全集上它反而最优**
7. ICP 内点数可判别 —— `inlier_ratio` 饱和在 1.0
8. fitness 否决线 —— 扫描证明无任何阈值能改善
9. **TEASER 最大团可判别 —— 别名团反而更大**
10. 别名是跨楼层 —— 单层,Δz 是 4.14° 倾斜假象
11. 建图重影 → 配准差 → 可见性为负 → 错锁 —— 换 \|dz\| 小九倍的地图重测,
    配准从 0.0905 修到 0.0084,**可见性证据纹丝不动**
12. `basin_separated` 放过了错锁 —— 开修正后该 case 一字未变;
    真正不成立的是合取式另一项
13. 让模糊门更常生效 = 更保守 = 更安全 —— 锁定数不变但组成变差
14. RHPD 块权重降权 —— 建图召回 24%→32%,但 today20 正确数 12→11

> **每一条都是"先测再改"才没写进代码。任何新想法先设计可证伪测试。**
